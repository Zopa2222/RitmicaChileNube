## Cuerpo del Correo:

Estimado usuario,

Adjunto encontrará los documentos para comenzar a usar el **Sistema de Puntajes Rítmica Chile**.

### 📚 Documentos Incluidos:

1. **GUIA_RAPIDA.md** ⚡
   - Comienza aquí si es tu primera vez
   - 5 pasos simples para empezar en minutos
   - Recomendado: léelo primero

2. **MANUAL_USUARIO.md** 📖
   - Manual completo y detallado
   - Explica cada paso con más detalle
   - Incluye preguntas frecuentes
   - Consulta aquí si tienes dudas

3. **FORMATO_EXCEL.md** 📄
   - Especificaciones técnicas del archivo Excel
   - Estructura requerida de datos
   - Cómo preparar tu archivo
   - Errores comunes y soluciones

4. **VIDEO TUTORIAL** 🎥
   - Demostración completa del flujo principal
   - Ver en acción: crear campeonato → ingresar puntajes → exportar
   - Recomendado: ver antes de tu primer uso

### 🚀 Primeros Pasos Recomendados:

1. **Mira el video** para entender el flujo (5-10 min)
2. **Lee la guía rápida** (2-3 min)
3. **Prepara tu archivo Excel** según FORMATO_EXCEL.md
4. **Abre la aplicación** en http://localhost:4200
5. **Consulta el manual completo** si tienes dudas

### ⚠️ Punto Importante:
El archivo Excel que cargas al sistema es fundamental. Asegúrate de:
- Que esté en formato .xlsx
- Que contenga categorías y gymnasts claramente definidas
- Que no tenga filas vacías
- Revisar FORMATO_EXCEL.md para más detalles

### 💡 Tips:
- El sistema calcula puntajes automáticamente según reglas FIG
- Puedes editar campeonatos anteriores desde "Ver Campeonatos"
- Los resultados se exportan fácilmente a Excel
- Las celdas rojas indican diferencias >0.6 entre jueces (revisa)

### ❓ Soporte:
Si tienes preguntas o problemas:
1. Consulta la sección "Preguntas Frecuentes" del manual
2. Revisa FORMATO_EXCEL.md si es un problema con el Excel
3. Contacta con el administrador del sistema si persiste el problema
